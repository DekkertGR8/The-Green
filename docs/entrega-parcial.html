Alcance y temática

The Green es un café-bar de identidad vintage e industrial. El proyecto parte de una base React + TypeScript + Vite y reconstruye la interfaz (menú, header y footer) con una paleta de hierro, crema y latón, tipografía clásica y vistas adaptables.

Toda la operación del local se gestiona en vivo desde el Mock API asignado. Cada recurso tiene acceso directo en el menú principal, listado dinámico (tarjetas o tablas) y formularios para registrar y actualizar registros.

Recursos integrados: Productos, Categorías, Usuarios, Clientes, Órdenes y Estados de la orden.
